# Same letters

Given two words, `first` and `second`, made of the lowercase letters a to z, return `true` if they use exactly the same letters the same number of times, in any order, and `false` otherwise.

## Example

"listen" and "silent" use the same letters, so the answer is `true`. "aab" and "abb" don't, because each has a different letter twice.

## Limits

- Each word has from 0 to 50,000 letters.
- Aim for O(n) time.
