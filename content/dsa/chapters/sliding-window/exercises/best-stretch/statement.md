# Best stretch of sales

A shop records its `sales` for each day. Return the highest total of any `k` days in a row.

## Example

With `sales = [4, 2, 7, 1, 8, 3]` and `k = 3`, the totals of each three days in a row are 13, 10, 16, and 12, so the answer is 16.

## Limits

- From 1 to 100,000 days, each with sales between 0 and 10,000.
- `k` is between 1 and the number of days.
- Aim for O(n) time.
