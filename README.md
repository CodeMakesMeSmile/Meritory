# Meritory

Meritory is a study tool for software engineering interviews. The web app will be the core practice platform while the companion mobile app is for shorter and more casual exercises and review. 
Goal is to force active recall on the web through leetcode style questions, architecture design with diagrams and explanation, and live coding practice.
The mobile app will reinforce learned material (or help identify gaps in knowledge) through multiple choice, matching, ordering, and other question types. Its features should be available offline.
AI will be integrated for long form project evaluations.

The prototype is in Figma: [Meritory Prototype](https://www.figma.com/design/bNJ7xsT25s2zAdOr1MZ9Ug). Open the Screens page and pick a flow: the web core loop, the mobile core loop, or the handoff where a failed web attempt turns into phone recall and comes back as a fresh check on the web. Tokens and components, in light and dark, are on the Components page.
